# How the official image starts, and what has to change

Inspected `ghcr.io/azuracast/azuracast:stable` built 2026-10-21 17:47 UTC (AzuraCast 0.23.9,
Debian 13, PHP 8.5.12, ~3 GB).

## Startup chain

`tini -- /usr/local/bin/my_init --no-main-command`, as **root**:

1. `my_init` dumps the environment to `/container.env`, then runs every `/etc/my_init.d/*.sh`.
2. It `exec`s `supervisord -c /etc/supervisor/supervisord-full.conf`, which includes
   `minimal.conf.d/*` (mariadb, valkey), `full.conf.d/*` and every station's
   `/var/azuracast/stations/*/config/supervisord.conf`.
3. The `startup` program (`app_startup`) waits for redis and the DB, runs
   `azuracast_cli azuracast:setup --init`, then `supervisorctl start` php-fpm, centrifugo,
   nginx and finally `all`.

| init script | does | as non-root |
|---|---|---|
| 00_disable_mariadb / redis | removes a supervisor conf when the host isn't localhost | needs write to `/etc/supervisor` (or skip: we always run both) |
| 00_setup_user | `usermod`/`groupmod` azuracast to PUID/PGID | impossible; replaced (see UID below) |
| 01_self_signed_ssl | self-signed cert in `storage/acme` | works once the dir is ours |
| 02_install_extra_packages | `apt-get install` on boot | drop |
| 03_persist_dir | mkdir + chown storage dirs | mkdir works, chown not needed |
| 04_mariadb_conf, 05_*_conf, 06_php_conf | render templates with `dockerize` into `/etc/mysql`, `/etc/nginx`, `/usr/local/etc/php`, `/var/azuracast/centrifugo` | need those files writable by us (own them at build) |
| 05_setup_db | MariaDB init/upgrade, then `gosu mysql` | works without the gosu branch (it only switches when uid is 0) |
| 07_sftpgo_conf | ssh host keys + port env | works |
| 08_plugin_mode | `gosu azuracast composer update` | drop (plugins off) |
| 10_clear_temp | empties `www_tmp` | works |

## Root is assumed in four places

- **supervisord** runs with `user=root` and every program has `user=azuracast`, `user=mysql` or
  `user=valkey`. A non-root supervisord refuses `user=` for anyone but itself.
- **Station programs** are generated by PHP (`backend/src/Radio/Configuration.php`, hardcoded
  `'user' => 'azuracast'`) into each station's `supervisord.conf`.
- **`gosu`** in `azuracast_cli`, `app_startup` and `05_setup_db` (each only when not already
  the target user).
- **`usermod`** to match PUID/PGID.

Plan: one Unix user for everything, `azuracast`, with the **same UID/GID as the Pelican
container user** (set at build time). Then `whoami` is `azuracast`, every `gosu` branch is
skipped, and supervisor's `user=azuracast` is a no-op. Strip `user=mysql` / `user=valkey` /
`user=root` from our copies of the supervisor confs. The PHP-generated station confs need no
change.

## Volumes: the image must be flattened

The image declares `VOLUME`s for `/var/azuracast/{backups,stations,storage/*}` and
`/var/lib/mysql`. A child image can't remove inherited `VOLUME`s, so Docker would create
anonymous volumes there on every server and the data would never reach `/home/container`
(lost on reinstall, invisible to Pelican backups and disk limits).

So the Dockerfile is `FROM scratch` + `COPY --from=upstream / /`, then re-declares only `ENV`
(list below), `WORKDIR` and our `ENTRYPOINT`. Those paths become symlinks into
`/home/container`, created at build time.

Upstream `ENV` to carry over: `PATH` (includes `/var/azuracast/storage/shoutcast2`),
`PHP_INI_DIR`, `TZ`, `LANG`/`LC_*`, `APPLICATION_ENV=production`, `MYSQL_*`,
`ENABLE_REDIS`, `REDIS_*`, `NGINX_RADIO_PORTS`, `NGINX_WEBDJ_PORTS`, `COMPOSER_PLUGIN_MODE`,
`ADDITIONAL_MEDIA_SYNC_WORKER_COUNT`, `ENABLE_WEB_UPDATER` (set to false: Pelican updates the
image). `MYSQL_PASSWORD` defaults to a public value upstream; generate one per server on first
boot instead.

## Ports

- Web: nginx listens on `AZURACAST_HTTP_PORT` and `AZURACAST_HTTPS_PORT` (template line 55-56)
  -> HTTP on the primary allocation (`SERVER_PORT`). HTTPS is optional and, when used, needs
  its own allocation.
- Streams: each station is given a block of 10 ports from `AUTO_ASSIGN_PORT_MIN`..`MAX`
  (default 8000-8499). Each station also writes an nginx conf that nginx includes, so
  listeners can use `/listen/...` through the web port. Only live DJs (harbor) and direct
  Icecast need real ports. So the egg can work on **one port**, and extra allocations unlock
  direct streams.
- SFTP: `AZURACAST_SFTP_PORT` (default 2022), optional allocation.

## Writable paths we must own at build time

`/etc/nginx` (sites-available/enabled, nginx.conf), `/etc/mysql/conf.d`,
`/usr/local/etc/php` + `php-fpm.conf`, `/etc/supervisor` (only if we keep the disable
scripts), `/var/azuracast/{centrifugo,sftpgo,www_tmp}`, `/run` (supervisor.sock,
supervisord.pid, mysqld, redis), `/container.env`.
